# Измеритель задержки эффектов (прототип .NET)

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Прототип для Windows WPF/.NET 8, использующий `NAudio.Asio` для отображения и открытия локальных драйверов ASIO и измерения общей задержки аудиоинтерфейса и педалборда туда-обратно.

## Запуск

```powershell
dotnet restore
dotnet run --project .\EffectsLatencyTester.csproj
```

Программа сначала выбирает первый доступный драйвер, считывает частоту дискретизации, буфер и каналы, генерирует тестовые импульсы, обнаруживает возвратный импульс и показывает входную, выходную и объединённую осциллограммы.

## Подключение и измерение

Подключите ASIO-выход интерфейса ко входу педалборда, а выход педалборда — к ASIO-входу интерфейса. Отключите Direct Monitoring и начните с низкой громкости.

Первое измерение — общая задержка туда-обратно. Чтобы получить задержку педалборда, сначала измерьте базовую задержку при прямом соединении выхода и входа интерфейса, затем измерьте цепь эффектов:

```text
Задержка педалборда = Общая задержка цепи - Базовая задержка интерфейса
```

Окно осциллограмм поддерживает горизонтальную прокрутку, перетаскивание, масштабирование с помощью `Ctrl` + колёсико и два щелчка для записи T1/T2 и вычисления разницы.

## Языки

При запуске программа читает язык интерфейса системы. Доступны русский, английский, китайский (упрощённый и традиционный), японский, корейский, испанский, французский, немецкий, итальянский и бразильский португальский. Для остальных языков используется английский.

## Публикация

```powershell
.\publish.ps1
```

Без параметров скрипт создаёт автономные одиночные файлы для `win-x86`, `win-x64` и `win-arm64`. Для одной архитектуры укажите `-Runtime win-x64`, `-Runtime win-x86` или `-Runtime win-arm64`. Установка .NET не требуется, но нужен соответствующий драйвер ASIO. Linux и macOS пока не поддерживаются, поскольку проект использует WPF и `NAudio.Asio`.
