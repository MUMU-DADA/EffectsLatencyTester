# Измеритель задержки эффектов (прототип .NET)

[English](../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Настольное приложение .NET 8 на Avalonia для измерения общей задержки аудиоинтерфейса и педалборда туда-обратно. В Windows используется ASIO, в macOS — Core Audio, а в Linux — PortAudio с ALSA/PipeWire/JACK.

## Запуск

```powershell
dotnet restore
dotnet run --project .\EffectsLatencyTester.csproj
```

## Скриншот

![Снимок экрана приложения](Snipaste.png)

Программа сначала выбирает первое доступное аудиоустройство, считывает частоту дискретизации, буфер и каналы, генерирует тестовые импульсы, обнаруживает возвратный импульс и показывает входную, выходную и объединённую осциллограммы.

## Подключение и измерение

Подключите аудиовыход интерфейса ко входу педалборда, а выход педалборда — к аудиовходу интерфейса. Отключите Direct Monitoring и начните с низкой громкости.

Первое измерение — общая задержка туда-обратно. Чтобы получить задержку педалборда, сначала измерьте базовую задержку при прямом соединении выхода и входа интерфейса, затем измерьте цепь эффектов:

```text
Задержка педалборда = Общая задержка цепи - Базовая задержка интерфейса
```

Окно осциллограмм поддерживает горизонтальную прокрутку, перетаскивание, масштабирование с помощью `Ctrl` + колёсико и два щелчка для записи T1/T2 и вычисления разницы.

## Языки

При запуске программа читает язык интерфейса системы. Доступны русский, английский, китайский (упрощённый и традиционный), японский, корейский, испанский, французский, немецкий, итальянский и бразильский португальский. Для остальных языков используется английский.

## Публикация

```powershell
.\publish.ps1
```

Без параметров скрипт создаёт автономные одиночные файлы для `win-x86`, `win-x64`, `win-arm64`, `osx-x64`, `osx-arm64`, `linux-x64` и `linux-arm64`. Для одной платформы укажите, например, `-Runtime win-x64`, `-Runtime osx-arm64` или `-Runtime linux-x64`. Установка .NET не требуется. В Windows нужен соответствующий драйвер ASIO; macOS и Linux используют нативные аудио API через PortAudio. Пути macOS и Linux ещё необходимо проверить на целевых системах с реальным оборудованием.

Имя каждого опубликованного файла имеет вид `EffectsLatencyTester_<os-arch>`; для Windows используется расширение `.exe`, а для macOS и Linux расширения нет.
